# Zhang Lab — pilot static site

Brain Disorders & Genomics, Tongji University School of Medicine.
Plain HTML, CSS and JavaScript. No build step, no framework, no package install.

## Files

```
index.html          Home — hero figure, research summary, tool, featured papers
research.html       Research directions
ming-zhang.html     PI page + lab member placeholders
publications.html   Filterable publication list
tools.html          Spliformer-V2 documentation
contact.html        Recruitment and contact
assets/
  style.css         All styling
  site.js           Publication rendering, filters, nav state
  publications.js   >>> EDIT THIS to add papers <<<
  img/*.svg         Original figures (see make_art.py)
make_art.py         Regenerates the research/decorative SVGs (python3, no deps)
make_figures.py     Regenerates the hero and research banner figures
```

## Publishing to GitHub Pages

1. Create a repository — e.g. `TJ-zhanglab/TJ-zhanglab.github.io` for a
   user/org site, or any name for a project site.
2. Copy these files into the repository root and push.
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
4. Live within a minute or two at `https://<org>.github.io/` or
   `https://<org>.github.io/<repo>/`.

A custom domain goes in Settings → Pages → Custom domain, plus a `CNAME`
file in the repo root containing the bare domain.

### Alternatives

- **Netlify Drop** — drag the folder onto https://app.netlify.com/drop
- **Cloudflare Pages** or **Vercel** — connect the repo, no build command,
  output directory `/`

## Adding a publication

Open `assets/publications.js`, copy any entry, and put it at the top:

```js
{
  year: 2026,
  title: "…",
  authors: "First A*, Second B*, … Ming Zhang#",
  venue: "Journal, volume:pages",
  url: "https://doi.org/…",
  role: "corresponding",   // first | co-first | corresponding | co-corresponding
  topic: "als",            // als | epigenetics | ai | parkinsons | other
  featured: true           // also show on the home page (max 4 shown)
}
```

`role` drives the tag on the right of the title; `topic` drives the filter
chips. Nothing else needs touching.

## Swapping in real images

- **PI portrait** — `assets/img/ming-zhang.jpg` (840 × 1040, cropped to the
  420:520 frame the page uses). Swap the file to change the photo.
- **Figures** — the three research graphics are generated by `make_art.py`.
  Replace them with real figures from your papers if you prefer; the layout
  takes any aspect ratio near 13:8.
- All artwork here was drawn for this site, so there are no licensing
  questions. Anything you swap in should be your own or properly licensed.

## Design

Palette and type are set once at the top of `style.css` as CSS custom
properties — change `--violet`, `--ink` or `--paper` there and the whole site
follows. Fonts are Fraunces (display), IBM Plex Sans (body) and IBM Plex Mono
(labels and code), loaded from Google Fonts.
