Spliformer

A self-attention deep learning tool that predicts splicing from pre-mRNA sequence and visualises the attention weight score of splicing motifs. Give it a VCF and it returns, for each variant, the probability that a nearby position acts as a donor, an acceptor, or neither. In motif mode it produces attention heatmaps for wild-type and variant sequence side by side, which is how you see why the model changed its mind.

Install

Tested on Debian 4.19.235-1 x86_64, Python 3.9.6, PyTorch 1.9.0 (GPU). Install PyTorch first, then:

conda create -n Spliformer python=3.9
conda activate Spliformer
git clone https://github.com/TJ-zhanglab/Spliformer.git
cd Spliformer
pip install -r requirements.txt
python setup.py install

A Dockerfile ships with the repository if you would rather not configure dependencies by hand — docker build -t spliformer:v1 . and mount your data directory with -v $(pwd):/data.

Two modes

# general — predict the effect of variants on splicing
spliformer -T general -I ./examples/inputhg19.vcf -O ./output.vcf \
  -R /path/genome.fa -A ./reference/hg19anno.txt

# motif — attention heatmaps for wild-type vs variant sequence
spliformer -T motif -I ./examples/inputhg19-motif.vcf \
  -R /path/genome.fa -A ./reference/hg19anno.txt

Run general mode first, then take the SNVs worth understanding into motif mode.

Parameters

FlagMeaning
-Tgeneral or motif. Default general.
-IInput VCF with the variants of interest.
-OOutput VCF — general mode only.
-RReference genome FASTA, GRCh37/hg19 or GRCh38/hg38, downloaded and unzipped.
-AAnnotation file built from GENCODE v39; hg19 and hg38 versions ship in reference/.
-DOptional. Distance window between variant and gained or lost splice site, 0–4999. Default 50.
-MOptional. Mask annotated gains and unannotated losses — 0 off, 1 on. Default 0.
-NOptional. Number of motifs in the attention heatmap, 0–40. Default 10.

Reading the output

The INFO field is Ref>Alt|gene|increased acceptor dist:score|decreased acceptor dist:score|increased donor dist:score|decreased donor dist:score. For chr2:179642185 G>A, the result G>A|TTN|2:0.00|38:0.01|2:0.83|-38:0.31 says the position 2 bp downstream gains donor usage by 0.83, while a donor 38 bp upstream loses 0.31 — a donor shift, not an acceptor one.

Spliformer-V2

Where Spliformer predicts splicing, Spliformer-V2 predicts how much — splice site usage rather than presence, and separately for each tissue. Built on the Segment-NT architecture and fine-tuned on paired genome and transcriptome datasets, it covers 18 human tissues, of which twelve are CNS. As far as we know that is the most complete splicing model available for human brain regions and spinal cord. It is genotype-aware and takes standard VCF in, annotated VCF out.

Install and run

Tested on Debian 6.1.140-1 x86_64, Python 3.8.19, PyTorch 2.4.1 (GPU).

git clone https://github.com/TJ-zhanglab/Spliformer-V2.git
cd Spliformer-V2
conda env create -f spliformerV2.yml
conda activate spliformerv2

python run.py \
  -I ./example/input/input19.vcf \
  -O ./output/output.vcf \
  -R ./reference/hg19.fa \
  -A ./reference/grch37.txt \
  -T LMC \
  -G 1 \
  -M 0
FlagMeaning
-I -OInput and output VCF.
-RReference genome FASTA, hg19 or hg38, unzipped into reference/.
-AGENCODE v39 annotation; hg19 and hg38 versions ship in reference/.
-TTissue to predict for.
-GGenotypes present in the VCF — 1 yes, 0 no.
-MOptional. Mask annotated gains and unannotated losses. Default 0.

Reading the output

Predictions land in the INFO field as a pipe-delimited string: alternate allele, gene, four usage scores — increased and decreased acceptor, increased and decreased donor — then four distances from the variant to the site carrying each maximum.

SpatialE

A gene set spatial enrichment tool. SpatialE estimates an entropy-weighted differential gene expression matrix across spatial clusters, then asks how significantly a predefined gene set concentrates in one region compared with randomly sampled gene sets. Combined with Seurat, it locates the region where a gene set or cell type is enriched. This is the method behind the NOMO1 link to ALS reported in Brain in 2024.

Install

install.packages("devtools")
library(devtools)

options(timeout = 9999999)  # the download is large
install_github("https://github.com/TJ-zhanglab/SpatialE.git")

Built-in datasets ship with the package; the User's guidance directory in the repository walks through a worked example.
